# Basic Networking Commands in RHEL 8

Networking is a core aspect of Linux system administration. This guide covers essential networking commands in RHEL 8, providing practical examples and a lab to practice them.

---

## **1. Key Networking Commands**

| Command                 | Description                                                     |
|-------------------------|-----------------------------------------------------------------|
| `ip -a`                    | Show/manipulate network interfaces and routing. also to check the ip address                |
| `nmcli`                 | Command-line tool for managing NetworkManager.                |
| `ping`                  | Check connectivity to a host.                                 |
| `traceroute`            | Trace the route packets take to a host.                       |
| `netstat`               | Display network connections and statistics (deprecated).      |
| `ss`                    | Display detailed network socket information (replacement for `netstat`). |
| `dig`                   | Query DNS servers for domain name information.               |
| `nslookup`              | Query DNS for domain name resolution.                         |
| `curl`                  | Transfer data from a URL.                                     |
| `wget`                  | Retrieve files from a URL.                                    |

---

## **2. Examples**

### **2.1. Check IP Configuration**
```bash
ip addr show
```

### **2.2. Add an IP Address to an Interface**
```bash
ip addr add 192.168.1.100/24 dev eth0
```

### **2.3. Check Connectivity with `ping`**
```bash
ping -c 4 google.com
```

### **2.4. Trace the Route to a Host**
```bash
traceroute google.com
```

### **2.5. Display Active Network Connections with `ss`**
```bash
ss -tuln
```

### **2.6. Query DNS with `dig`**
```bash
dig example.com
```

### **2.7. Transfer Data Using `curl`**
```bash
curl -O https://example.com/file.txt
```

## **4. Best Practices**

- Always verify network configurations after making changes using `ip` or `nmcli`.
- Use `ss` instead of `netstat` for better performance and detailed output.
- Test connectivity regularly using `ping` or `traceroute`.
- Ensure DNS resolution works as expected using `dig` or `nslookup`.
