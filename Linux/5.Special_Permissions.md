## Special Permissions: Controlling File Access

This document outlines three special permissions that can be applied to files and directories:

**1. SUID (Set User ID)**

* **Behavior:** When a file with SUID set is executed, the process runs with the privileges of the file's *owner*, not the user executing it.
* **Example:**

    1. Create a script (e.g., `my_script.sh`) with the following content:

       ```bash
       #!/bin/bash
       echo "This script runs with root privileges."
       whoami
       ```

    2. Make the script executable: `chmod +x my_script.sh`
    3. Set the owner of the script (e.g., root): `chown root:root my_script.sh`
    4. Apply SUID: `chmod u+s my_script.sh` 
    5. Execute the script as a regular user: `./my_script.sh` 

    The output will show that the script is running as the root user, even though you executed it as a regular user.

**2. SGID (Set Group ID)**

* **On executable files:** The process runs with the privileges of the file's *group*.
* **On directories:** Files created within the directory inherit the directory's group ownership.
* **Example:**

    1. Create a directory: `mkdir my_dir`
    2. Set the directory group: `chgrp my_group my_dir`
    3. Apply SGID: `chmod g+s my_dir`
    4. Create a file within the directory: `touch my_dir/my_file`
    5. Verify group ownership: `ls -l my_dir/my_file` 

    The output of `ls -l` will show that `my_file` belongs to the `my_group`, even if the user creating the file is not a member of that group.

**3. Sticky Bit**

* **Behavior:** Only the file owner or the root user can delete files within the directory.
* **Example:**

    1. Create a directory: `mkdir shared_dir`
    2. Apply Sticky Bit: `chmod o+t shared_dir` 
    3. Users within the directory will only be able to delete their own files, not those created by others.

**Note:**

* Special permissions can be set and removed using the `chmod` command. 

**Disclaimer:** Modifying file permissions can have security implications. Exercise caution and ensure you understand the potential consequences before applying special permissions.
