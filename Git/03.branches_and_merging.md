# Branches and Merging

Branches allow you to work on different features or experiments independently without affecting the main codebase.

**1. Creating a Branch:**

* **`git branch <branch_name>`:** Creates a new branch.
* **`git checkout <branch_name>`:** Switches to the specified branch.

**2. Merging Branches:**

* **`git merge <branch_name>`:** Merges the specified branch into the current branch.
* **Resolve Conflicts:** If conflicts arise during merging, manually resolve them and then stage and commit the changes.

**3. Branching Strategies:**

* **Feature Branches:** Create branches for specific features and merge them back into the main branch when complete.
* **Bug Fix Branches:** Create branches to fix bugs and then merge them back into the main branch.

**4. Common Branching Workflows:**

* **Git Flow:** A popular branching model with dedicated branches for releases, features, and hotfixes.
* **GitHub Flow:** A simpler workflow that emphasizes frequent small commits and relies heavily on pull requests.

**Mastering branches and merging is crucial for efficient collaboration and managing complex projects.**
