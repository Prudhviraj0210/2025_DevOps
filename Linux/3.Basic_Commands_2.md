# Linux Basic Commands


### File Types in Linux

| **File Type**      | **Symbol** | **Description**                                   |
|---------------------|------------|---------------------------------------------------|
| **Normal File**     | `-`        | A regular file (e.g., text files, binary files).  |
| **Directory**       | `d`        | A folder containing other files or directories.   |
| **Link File**       | `l`        | A symbolic link (shortcut to another file).       |
| **Block File**      | `b`        | A block device file (e.g., hard disk, floppy disk).|
| **Character File**  | `c`        | A character device file (e.g., keyboard, mouse).  |
| **Socket**          | `s`        | A socket file used for inter-process communication. |
| **Named Pipe**      | `p`        | A special file for unidirectional data flow (FIFO).|

### Symbolic Links

#### Types of Links
1. **Soft Link** (Shortcut):
   - Created using `ln -s`.
   - Can be created across partitions.
   - Inode number differs from the source file.
   - Broken if the source file is deleted.
   ```bash
   ln -s source_file destination
   ```

2. **Hard Link** (Backup):
   - Created using `ln`.
   - Cannot be created across partitions.
   - Same inode number as the source file.
   - Retains data even if the source file is deleted.
   ```bash
   ln source_file destination
   ```

## Regular Expressions, Pipelines & I/O Redirection

### Using `grep` Command
- **Basic Syntax**:
  ```bash
  grep pattern filename
  ```
- **Examples**:
  - Search for a word:
    ```bash
    grep root /etc/passwd
    ```
  - Ignore case sensitivity:
    ```bash
    grep -i kernel ktfile
    ```
  - Display lines before and after a match:
    ```bash
    grep -nA2 wheel /etc/group
    grep -nB2 wheel /etc/group
    ```
  - Exclude lines with a pattern:
    ```bash
    grep -v kernel ktfile
    ```
  - Highlight matches in color:
    ```bash
    grep --color root /etc/passwd
    ```

### Combining `grep` with Other Commands
- Use `|` to pipe commands:
  ```bash
  ls -l | grep ktfile
  cat ktfile | grep kernel
  ```

### Filter Commands
- **`less`**: View output line by line or page by page.
  ```bash
  less /etc/passwd
  ```
- **`more`**: Similar to `less` but simpler.
  ```bash
  more /etc/passwd
  ```
- **`head`**: Display the first 10 lines of a file.
  ```bash
  head /etc/passwd
  head -n 5 /etc/passwd
  ```
- **`tail`**: Display the last 10 lines of a file.
  ```bash
  tail /etc/passwd
  tail -n 5 /etc/passwd
  ```

## 8. File Permissions

### Access Levels
- **User Levels**:
  1. **Owner/User**: User who owns the file.
  2. **Group**: Group associated with the file.
  3. **Others**: All other users.

- **Access Modes**:
  1. `r`: Read-only.
  2. `w`: Write, edit, delete, or append.
  3. `x`: Execute or run the file.

### Setting Permissions
- **Symbolic Method**:
  ```bash
  chmod u=rwx,g=rw,o=r filename
  chmod u+x filename
  chmod go-wx filename
  ```
- **Numeric Method**:
  ```bash
  chmod 764 filename
  chmod 777 filename
  ```
  - Values:
    - `r = 4`
    - `w = 2`
    - `x = 1`

### Viewing File Permissions
- Use `ls -l`:
  ```bash
  ls -l filename
  ```

### `umask`
- Default permissions are determined by the `umask` value.
- **Default Values**:
  - Files: `644`
  - Directories: `755`
- **Modify `umask`**:
  ```bash
  umask 002
  ```
