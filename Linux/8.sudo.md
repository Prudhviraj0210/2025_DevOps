# Understanding and Using `sudo`

## What is `sudo`?

The `sudo` command allows a permitted user to execute a command as the superuser or another user. By default, it lets users temporarily gain superuser privileges to execute administrative tasks while ensuring security and accountability through logging.

### Why Use `sudo`?
- **Controlled Privileges**: Users gain root-level access only when needed.
- **Security**: Prevents full-time root access, minimizing potential damage caused by mistakes or malicious actions.
- **Auditing**: Tracks all administrative commands in the system logs.

## `sudoers` File

- The `/etc/sudoers` file determines user permissions for using `sudo`.
- Use `visudo` to safely edit the `sudoers` file:
  ```bash
  sudo visudo
  ```

### Key Syntax in `sudoers` File:
```plaintext
<user>  ALL=(ALL) ALL
```
- **First `ALL`**: User can execute commands on any host.
- **Second `(ALL)`**: User can execute commands as any user.
- **Third `ALL`**: User can run any command.

### Example: Adding a User to `sudo`
- Add the following line using `visudo`:
  ```plaintext
  username  ALL=(ALL) NOPASSWD: ALL
  ```
  This grants `username` root privileges without requiring a password.

## Common `sudo` Commands and Usage

### Basic Syntax:
```bash
sudo <command>
```

### Examples:
1. **Update the system**:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

2. **Edit a system configuration file**:
   ```bash
   sudo nano /etc/hosts
   ```

3. **Restart a service**:
   ```bash
   sudo systemctl restart apache2
   ```

4. **Switch to root user**:
   ```bash
   sudo -i
   ```

Learn how to:

### Lab Steps:

#### 1. **Granting `sudo` Privileges to a User**

1. Switch to root user:
   ```bash
   su -
   ```

2. Add a new user (e.g., `labuser`):
   ```bash
   adduser labuser
   ```

3. Grant `labuser` sudo privileges by adding them to the `sudo` group:
   ```bash
   usermod -aG sudo labuser
   ```

4. Verify `labuser` can use `sudo`:
   ```bash
   su - labuser
   sudo whoami
   ```
   Output:
   ```plaintext
   root
   ```

---

#### 2. **Using `sudo` to Manage the System**

1. **Update the System**:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

2. **Create a New Directory in `/root`**:
   ```bash
   sudo mkdir /root/labtest
   ```
   Verify:
   ```bash
   ls -ld /root/labtest
   ```

3. **Modify the `sudoers` File**:
   ```bash
   sudo visudo
   ```
   Add the line:
   ```plaintext
   labuser ALL=(ALL) NOPASSWD: ALL
   ```

---

#### 3. **Testing `sudo` with Restrictions**

1. Restrict `labuser` to only restart a specific service (e.g., `nginx`):
   ```plaintext
   labuser ALL=(ALL) NOPASSWD: /bin/systemctl restart nginx
   ```

2. Test the restriction:
   ```bash
   sudo systemctl restart nginx  # Allowed
   sudo apt update               # Denied
   ```

### Cleanup (Optional)

1. Remove `labuser`:
   ```bash

   ```

2. Remove the `/root/labtest` directory:
   ```bash
   sudo rm -r /root/labtest
   ```

## Troubleshooting

### Common Issues:
1. **`sudo: command not found`**:
   - Ensure `sudo` is installed:
     ```bash
     apt install sudo
     ```

2. **Permission Denied Errors**:
   - Check the `sudoers` file for correct syntax and privileges.

3. **Broken `sudoers` File**:
   - Boot into recovery mode or use a live CD to fix the `/etc/sudoers` file.
