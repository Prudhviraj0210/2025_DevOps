# Managing Processes in RHEL 8

Process management is a fundamental skill for Linux system administrators. In RHEL 8, you can use various tools and commands to monitor, control, and optimize processes. This guide provides essential commands, examples, and a lab to practice managing processes.

---

## **1. Overview of Processes**

A process is an instance of a program in execution. Processes can be:
- **Foreground:** Directly controlled by the user.
- **Background:** Running without user intervention.

---

## **2. Key Commands for Process Management**

| Command                   | Description                                                    |
|---------------------------|----------------------------------------------------------------|
| `ps`                      | Display information about running processes.                  |
| `top`                     | Show real-time information about processes.                   |
| `htop`                    | Interactive real-time process viewer (requires installation). |
| `kill`                    | Terminate a process using its PID.                            |
| `pkill`                   | Terminate processes by name.                                  |
| `nice`                    | Start a process with a specific priority.                     |
| `renice`                  | Change the priority of a running process.                     |
| `jobs`                    | List background jobs in the current shell.                    |
| `fg`                      | Bring a background job to the foreground.                     |
| `bg`                      | Resume a background job.                                      |

---

## **3. Examples**

### **3.1. Viewing Processes**

**List All Processes:**
```bash
ps -e
```

**View Detailed Process Information:**
```bash
ps -aux
```

**Monitor Processes in Real-Time:**
```bash
top
```

**Filter Specific Process Using `grep`:**
```bash
ps -aux | grep httpd
```

---

### **3.2. Managing Process Priorities**

**Start a Process with a Lower Priority:**
```bash
nice -n 10 myscript.sh
```

**Change Priority of a Running Process:**
```bash
renice -n -5 -p <PID>
```

---

### **3.3. Controlling Processes**

**Kill a Process by PID:**
```bash
kill 1234
```

**Kill All Processes by Name:**
```bash
pkill httpd
```

**Suspend a Background Job:**
```bash
bg %1
```

**Resume a Background Job:**
```bash
fg %1
```

1. **Start a Process with a Lower Priority:**
   ```bash
   nice -n 15 sleep 300
   ```

   ```bash
   ps -eo pid,ni,cmd | grep sleep
   ```

   ```bash
   renice -n -10 -p <PID>
   ```

---

#### **Task 3: Terminate Processes**
1. **Start a Long-Running Process:**
   ```bash
   sleep 500 &
   ```

2. **List Background Jobs:**
   ```bash
   jobs
   ```

3. **Bring the Job to the Foreground and Terminate It:**
   ```bash
   fg %1
   Ctrl+C
   ```

4. **Kill a Process by Name:**
   ```bash
   pkill sleep
   ```

---

## **5. Best Practices**

- Use `htop` for an interactive view of processes (if available).
- Always verify the PID or name of a process before killing it.
- Monitor CPU and memory usage regularly using `top` or `ps`.
