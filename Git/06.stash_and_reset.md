# Git Stash and Reset

**1. Git Stash:**

* **`git stash`:** Temporarily saves uncommitted changes to the stack.
* **`git stash pop`:** Applies the most recently stashed changes.
* **`git stash list`:** Shows a list of stashed changes.
* **`git stash apply`:** Applies a specific stashed change without removing it from the stack.
* **`git stash drop`:** Removes the most recently stashed changes.

**2. Git Reset:**

* **`git reset --soft <commit_hash>`:** Discards all commits after the specified commit, but keeps the changes in the working directory.
* **`git reset --mixed <commit_hash>`:** Discards all commits after the specified commit and moves the changes to the staging area.
* **`git reset --hard <commit_hash>`:** Discards all commits after the specified commit and discards all changes.

**Use `git stash` to temporarily save your work and `git reset` to undo changes or revert to a previous state.**

**Use these commands with caution, as they can result in data loss.**
