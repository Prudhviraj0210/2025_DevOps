# Advanced Git Features

This section covers some more advanced Git features.

**1. Interactive Rebase:**

* **`git rebase -i <commit_hash>`:** Allows you to interactively modify the commit history.
* Useful for cleaning up commit messages, squashing commits, or reordering commits.

**2. Cherry-Picking:**

* **`git cherry-pick <commit_hash>`:** Applies a specific commit from another branch to the current branch.

**3. Submodules:**

* Allows you to include another Git repository as a subdirectory within your main repository.

**4. Git Hooks:**

* Scripts that run automatically at certain points in the Git workflow (e.g., before commit, after push).

**5. Git LFS (Large File Storage):**

* Designed to handle large files such as images, videos, and audio files more efficiently.

**6. Git Worktrees:**

* Allows you to check out multiple branches or even different repositories in separate working directories.

**Explore these advanced features to further enhance your Git workflow.**
