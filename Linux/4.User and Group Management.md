# Linux Basic Commands: User and Group Management

Learn to manage users and groups in Linux efficiently with this guide. This page is enhanced for creativity and clarity to boost your understanding and usage.

---

## 👤 User Management

### ➕ Creating Users
- **Add a New User**:
  ```bash
  adduser username
  ```
  Creates a new user with default settings.

- **Set Password for a User**:
  ```bash
  passwd username
  ```
  Assigns or changes the password for the specified user.

### 🔍 Viewing User Information
- **Show Current User**:
  ```bash
  whoami
  ```
  Displays the username of the currently logged-in user.

- **Display User Details**:
  ```bash
  id username
  ```
  Shows user ID, group ID, and other related information.

### ✏️ Modifying Users
- **Change User Information**:
  ```bash
  usermod options username
  ```
  Example: Change the shell for a user:
  ```bash
  usermod -s /bin/bash username
  ```

- **Delete a User**:
  ```bash
  userdel username
  ```
  Removes a user account from the system.

## 👥 Group Management

### ➕ Creating Groups
- **Add a New Group**:
  ```bash
  groupadd groupname
  ```
  Creates a new group.

### 🔄 Modifying Groups
- **Add a User to a Group**:
  ```bash
  usermod -aG groupname username
  ```
  Adds a user to the specified group.

- **Change Group Ownership**:
  ```bash
  chgrp groupname filename
  ```
  Changes the group ownership of a file or directory.

### 🔍 Viewing Group Information
- **List Groups for a User**:
  ```bash
  groups username
  ```
  Displays all groups a user belongs to.

- **Show Group Details**:
  ```bash
  getent group groupname
  ```
  Displays detailed information about a specific group.

### ❌ Deleting Groups
- **Remove a Group**:
  ```bash
  groupdel groupname
  ```
  Deletes a group from the system.

---

## 🔧 Special Commands for User and Group Management

- **List All Users**:
  ```bash
  cat /etc/passwd
  ```
  Outputs a list of all system users.

- **List All Groups**:
  ```bash
  cat /etc/group
  ```
  Outputs a list of all groups on the system.

- **Switch User**:
  ```bash
  su username
  ```
  Switches to another user account.

- **Check Who Is Logged In**:
  ```bash
  who
  ```
  Lists all logged-in users.

- **Log Out of Current Session**:
  ```bash
  logout / exit
  ```
  Logs out from the current session.
