# Linux Basic Commands

## 1. Creating, Removing, Copying, and Moving Files & Directories

### Creating a File in Linux
- **Using `cat` command**:
  ```bash
  cat > filename
  # Example:
  cat > ktfile
  Hello World
  Ctrl+D # Save the file
  ```
- **Display Content of a File**:
  ```bash
  cat filename
  # Example:
  cat ktfile
  ```
- **Append Data to an Existing File**:
  ```bash
  cat >> filename
  # Example:
  cat >> ktfile
  Ctrl+D # Save the changes
  ```
- **Create Multiple Files Using `touch` Command**:
  ```bash
  touch file1 file2 file3
  or
  touch file{1..10}
  it will create files as file1,file2,file3,etc
  # Verify:
  ls
  ```

### Creating a Directory
- **Create a Single Directory**:
  ```bash
  mkdir dirname
  # Example:
  mkdir ktdir
  ```
- **Create Nested Directories**:
  ```bash
  mkdir -p parent/{child1,child2}
  # Example:
  mkdir -p KernelTech/{Linux/{advlinux,linuxclstr},Aix/{hacmp,lpar},Storage/{san,netapp}}
  ```

### Copying Files & Directories
- **Copy Files**:
  ```bash
  cp source_file destination_dir
  # Example:
  cp file1 ktdir
  ```
- **Copy Directories**:
  ```bash
  cp -rvfp source_dir destination_dir
  # Example:
  cp -rvfp ktdir2 ktdir
  ```

### Moving & Renaming Files & Directories
- **Move Files**:
  ```bash
  mv filename destination_dir
  # Example:
  mv file2 ktdir
  ```
- **Rename a File**:
  ```bash
  mv old_name new_name
  # Example:
  mv ktfile kernelfile
  ```
- **Move a Directory**:
  ```bash
  mv dirname destination_dir
  # Example:
  mv ktdir ktdir2
  ```

### Removing Files & Directories
- **Remove a File**:
  ```bash
  rm filename
  # Example:
  rm ktfile
  ```
- **Remove an Empty Directory**:
  ```bash
  rmdir dirname
  # Example:
  rmdir ktdir
  ```
- **Remove a Directory with Contents**:
  ```bash
  rm -rf dirname
  # Example:
  rm -rf ktdir
  ```

## 2. File Viewing and Editing

### Using `vim` Editor
- **Open File in `vim`**:
  ```bash
  vim filename
  ```
- **Modes in `vim`**:
  - Insert Mode:
    - `i` - Insert at cursor.
    - `a` - Append after cursor.
  - Command Mode:
    - `dd` - Delete a line.
    - `yy` - Copy a line.
    - `p` - Paste below.
  - Save & Exit:
    - `:wq` - Save and quit.

### Viewing Files
- **Using `cat`**:
  ```bash
  cat filename
  ```
- **Using `less`**:
  ```bash
  less filename
  ```
- **Using `more`**:
  ```bash
  more filename
  ```
- **Using `head`**:
  ```bash
  head filename
  # Display custom lines:
  head -n 5 filename
  ```
- **Using `tail`**:
  ```bash
  tail filename
  # Display custom lines:
  tail -n 5 filename
  ```

## 3. File Permissions and Ownership

### Change Permissions
- **Symbolic Method**:
  ```bash
  chmod u+rwx,g+rw,o+r filename
  ```
- **Numeric Method**:
  ```bash
  chmod 764 filename
  ```

### Change Ownership
- **Change Owner**:
  ```bash
  chown user filename
  ```
- **Change Group**:
  ```bash
  chgrp group filename
  ```

## 4. Process Management
- **View Processes**:
  ```bash
  ps
  ```
- **Kill a Process**:
  ```bash
  kill PID
  ```
- **Real-Time Process Viewer**:
  ```bash
  top
  ```

## 5. Disk Usage
- **Disk Space Usage**:
  ```bash
  df -h
  ```
- **Disk Usage by Files/Directories**:
  ```bash
  du -h directory
  ```

## 6. Networking
- **Ping a Host**:
  ```bash
  ping host
  ```
- **Check IP Address**:
  ```bash
  ip addr
  ```
